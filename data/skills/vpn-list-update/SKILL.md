# Обогащение и актуализация каталога VPN

Локальный навык репозитория vpn-list. Обогащает каталог списков VPN записями из внешних источников (только добавление), проверяет целостность каталога и оформляет ручные дописывания. Существующие записи никогда не удаляются и не изменяются.

## Когда использовать

- Пользователь просит обогатить каталог из внешних источников
- Пользователь просит актуализировать версию каталога
- Пользователь просит проверить каталог: валидность, дубликаты, битые записи
- Пользователь просит добавить домен или подсеть в каталог вручную

## Инструкция

1. Обогащение из внешних источников - из корня репозитория:

```bash
python3 ${CLAUDE_SKILL_DIR}/scripts/enrich.py --catalog data/lists/catalog.json
```

2. Прочитать отчет скрипта: по каждому источнику - скачано, добавлено, пропущено. Строки с маркером `[!]` - недоступный источник или ошибка данных: код возврата 1, каталог при этом не портится (записи недоступного источника не добавлялись). Повторить запуск позже или отключить источник в `sources.json` (поле `enabled: false`)
3. Проверка целостности - после обогащения, ручных правок и при любом сомнении:

```bash
python3 ${CLAUDE_SKILL_DIR}/scripts/validate.py --catalog data/lists/catalog.json
```

4. Ручное добавление записи: отредактировать `data/lists/catalog.json` напрямую - новая запись в массив нужной группы: `source` = `manual`, `added` = текущая дата в формате `yymmdd`, затем поднять `version` до текущей даты и запустить validate. Записи с `source: manual` скрипты никогда не удаляют и не изменяют
5. При добавлении новой группы или нового внешнего источника - читать `reference.md` перед правками: группа меняет контракт формата, источник проходит проверку доступности

Правила каталога: только добавление от источников и вручную, версия каталога `yymmdd`, записи внутри группы сортированы по (`kind`, `value`), подсети не шире IPv4 /16 и IPv6 /32, лимит записей в группе - 5000. При потере или очистке рабочего каталога - восстановить закоммиченную версию из git (`git restore -- data/lists/catalog.json`) и запустить validate: обогащение только добавляет и не восстанавливает записи, исчезнувшие из источников. Полный контракт - `reference.md` и README репозитория.

## Примеры

1. «Обогати каталог VPN» - запустить enrich, пересказать отчет: что добавлено по группам, какие источники недоступны
2. «Проверь каталог» - запустить validate, показать ошибки или подтвердить валидность
3. «Добавь example.com в payments» - правка catalog.json: запись с `source: manual`, `added` - текущая дата, bump `version`, затем validate
