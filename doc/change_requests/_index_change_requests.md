# Индекс заданий на изменение репозитория vpn-list

Точка входа в каталог заданий на изменение (CR). Агент загружает индекс, а не каталог целиком, и по реестру и карте маршрутизации открывает только релевантные файлы. Индекс ведется вручную при любом изменении состава каталога. Порядок принятия решений агентом при отсутствии нормы - `project_standards.md`, раздел 07.06; канон ведения CR - `change_request_standards.md`.

---

## Обязательность применения

Тегание этого файла означает обязательное использование индекса при работе с заданиями на изменение. Агент:

1. Определяет релевантные файлы по реестру и карте маршрутизации
2. Открывает только релевантные файлы, а не каталог целиком
3. При любом изменении состава каталога (создание CR, смена статуса, перенос в спеку, архивация, отклонение) обновляет этот индекс

Индекс применяется при любой работе с заданиями на изменение независимо от явного тегирования.
