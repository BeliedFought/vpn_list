# Сводный индекс каталога навыков (хаб). Версия 4.15.0

Сводный индекс каталога навыков хаба `project_standards`. Точка входа: перечисляет все навыки - общие (`glob-`, слаг `hub_glob`), хаб-навыки (`hub-`, слаг `hub_loc`), агрегированные проектные навыки всех репозиториев из подпапок `doc/skills/ext/<repo>/` (`pg-`, `pg_`, слаг `pr_glob`). Локальные навыки (`pl-`/`pl_` или без префикса в `data/skills/`, слаг `pr_loc`) в синхронизацию и в этот индекс не входят - они отражены в собственном индексе `data/skills/_index_skills_pl.md` репозитория (генерирует `glob-update-indexes`; `index_nav_standards.md`, раздел 06.02). Существует только в хабе; в производных репозиториях используется локальный `_index_skills_repo.md` (генерируется навыком `glob-update-indexes`). Этот файл ведет навык `hub-sync-indexes` и редактируется только в хабе.

Навыки имеют индивидуальные версии (frontmatter `version` для plain-формата, `metadata.version` для формата Anthropic). Версия в заголовке этого индекса - версия пакета стандартов, с которым навыки совместимы.

Порядок принятия решений агентом при отсутствии или неоднозначности нормы - `project_standards.md`, раздел 07.06.

---

## Обязательность применения

Тегание этого файла (`@doc/skills/_index_skills_hub.md`) означает **обязательное применение** релевантных навыков, а не просто ознакомление с ними. Агент:

1. Определяет релевантные навыки по карте маршрутизации
2. Загружает указанные файлы навыков и выполняет их инструкции
3. Применяет все правила и рабочие процессы, описанные в навыках
4. Проверяет соответствие результата требованиям навыков перед завершением работы

Навыки применяются при наличии соответствующей задачи, независимо от того, был ли явно тегнут этот файл. Тегание лишь указывает агенту на необходимость явно загрузить каталог и применить подходящие навыки.

---

## Правило редактирования общих навыков

Общие навыки (каталоги `glob-*`, в производных репо также плоские `glob_*.md`), хаб-навыки (каталоги `hub-*`) и этот индекс редактируются только в центральном репозитории `project_standards` (хабе). В производных репозиториях общие навыки доступны только для чтения - они перезаписываются при синхронизации через навык `hub-sync-skills`. Локальный индекс `_index_skills_repo.md` в производных репозиториях генерируется навыком `glob-update-indexes` из локального состава `doc/skills/`.

## Реестр навыков

Все навыки хаба переведены на формат Anthropic Agent Skills и перечислены в разделе ниже; плоских навыков в корне `doc/skills/` нет.

### Навыки формата Anthropic Agent Skills (SKILL.md)

Навыки в формате SKILL.md - подпапки `doc/skills/` с `SKILL.md` и типовым префиксом: `glob-` - общие (слаг `hub_glob`), `hub-` - хаб (слаг `hub_loc`), `pg-` - проектные (слаг `pr_glob`); локальные `pl-`/`pl_` (или без префикса) живут в `data/skills/`, в этот индекс не входят и отражаются в `data/skills/_index_skills_pl.md`. Категория (область применения) - второй уровень префикса имени и колонка «Область»: слаг и название из закрытого справочника (`metadata.category` / `metadata.category_name`, `skill_plain_standards.md`, раздел 01.03). Оформление - `doc/standards/skill_anthropic_standards.md`. Деплой в боевые каталоги инструментов (`.opencode/skills/` и др.) - отдельный процесс навыка `glob-skill-deploy`; стандарт пакета его не описывает. Раздел ведет навык `hub-sync-indexes`; основные целевые инструменты - opencode, Claude Code, Kilo Code.

## Примечание о версионировании

Версия пакета стандартов, с которым совместимы навыки, указана в заголовке этого индекса и должна совпадать с версией `doc/standards/_index_standards.md`. Каждый навык имеет собственную версию во frontmatter (`version` для plain-формата, `metadata.version` для формата Anthropic). При обновлении пакета стандартов проверить навыки на совместимость и обновить версию в заголовке этого индекса.

## Автоактуализация индекса

Актуализация этого сводного индекса и реестра стандартов формализована в навыке `hub-sync-indexes` (только для хаба); локальные индексы производных репо ведет `glob-update-indexes`. Если пользователь тегнул этот файл (`@doc/skills/_index_skills_hub.md`) без конкретной команды или задачи, агент выполняет автоактуализацию:

1. Прочитать корневые каталоги навыков формата Anthropic (`doc/skills/glob-*/`, `doc/skills/hub-*/` с `SKILL.md`) и подпапки `doc/skills/ext/<repo>/`
2. Извлечь из каждого `SKILL.md`: `name`, `description`, `metadata.type`, `metadata.version`, `metadata.status`; из проектных навыков `ext/<repo>/` - имена записей (`pg-*/`, `pg_*.md`)
3. Обновить реестр навыков и сводку проектных навыков по репозиториям
4. Обновить карту маршрутизации: актуальные темы задач
5. Проверить версию в заголовке индекса: должна совпадать с версией пакета стандартов из `doc/standards/_index_standards.md`
6. Вывести отчет: какие навыки обновлены, какие добавлены/удалены, статус версии
