# Подбор и настройка зеркала PyPI

Подбирает рабочее зеркало PyPI на текущей машине, измеряет время отклика кандидатов, записывает выбранное зеркало в `~/.config/pip/pip.conf` и сообщает пользователю результат выбора. Держит список зеркал-кандидатов - обновляемый артефакт вне стандартов (норма алгоритма - `project_standards.md` 01.07).

## Когда использовать

- Установка зависимостей (`pip install`) завершается сетевой ошибкой или таймаутом скачивания
- `~/.config/pip/pip.conf` отсутствует или указывает на неработающее зеркало
- Пользователь просит настроить pip, выбрать зеркало или ускорить установку пакетов
- Создается новый проект и окружение (шаг установки зависимостей по `project_standards.md` 01.07)

## Инструкция

1. Проверить `~/.config/pip/pip.conf`: если файл существует и его `index-url` отвечает быстрым запросом (HEAD или короткий таймаут curl) - оставить без изменений и сообщить пользователю
2. При отсутствии или неработающем зеркале - прозвонить кандидатов из раздела «Кандидаты зеркал» ниже, измеряя время отклика каждого; официальный источник проверять последним
3. Выбрать самый быстрый доступный
4. Записать выбранное зеркало:

```bash
${CLAUDE_SKILL_DIR}/scripts/set_pip_conf.sh <mirror_url>
```

5. Сообщить пользователю выбранное зеркало и причину выбора (время отклика)

## Кандидаты зеркал (список обновляемый)

Список поддерживается в этом навыке: при обнаружении мертвого URL - исключить, при появлении нового устойчивого зеркала - добавить (правка только в хабе `project_standards`).

- `https://pypi.ru/simple/` - российское публичное зеркало
- `https://mirror.yandex.ru/pypi/simple/` - зеркало Яндекса
- `https://mirrors.aliyun.com/pypi/simple/` - зеркало Aliyun (стабильно работает из РФ)
- `https://pypi.org/simple/` - официальный источник (проверять последним, часто недоступен напрямую)

## Критерии завершения

- `~/.config/pip/pip.conf` существует и указывает на отвечающее зеркало
- Пользователю сообщены выбранное зеркало и время отклика
- Установка зависимостей проходит успешно

## Примеры

- «pip не может скачать пакеты» -> проверить pip.conf, прозвонить кандидатов, записать лучшее зеркало, повторить установку
- «настрой зеркало pip на этой машине» -> выполнить шаги 1-5 без установки пакетов

## Ограничения

- Удаление файлов и папок репозитория - перенос в `.trash/<slug>_<YYYYMMDDHHMM>/` (карантин, `project_standards.md` 01.01.06), а не удаление; чистить `.trash/` только по явному запросу пользователя
- Скрипт перезаписывает `~/.config/pip/pip.conf` целиком - перед записью убедиться, что текущий конфиг не отвечает (шаг 1)
- Скрипт меняет только конфигурацию pip пользователя; репозиторий и его файлы не затрагиваются
