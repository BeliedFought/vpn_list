# Навык: Подбор и настройка зеркала PyPI

## Описание

Подбирает рабочее зеркало PyPI на текущей машине, измеряет время отклика кандидатов, записывает выбранное зеркало в `~/.config/pip/pip.conf` и сообщает пользователю результат выбора. Список зеркал-кандидатов ведет в реестре `data/registries/pip-mirrors.md` репозитория (канон рантайм-данных - `doc/standards/skill_data_standards.md`); норма алгоритма - `project_standards.md` 01.07.

## Когда использовать

- Установка зависимостей (`pip install`) завершается сетевой ошибкой или таймаутом скачивания
- `~/.config/pip/pip.conf` отсутствует или указывает на неработающее зеркало
- Пользователь просит настроить pip, выбрать зеркало или ускорить установку пакетов
- Создается новый проект и окружение (шаг установки зависимостей по `project_standards.md` 01.07)

## Инструкция

1. Проверить `~/.config/pip/pip.conf`: если файл существует и его `index-url` отвечает быстрым запросом (HEAD или короткий таймаут curl) - оставить без изменений и сообщить пользователю
2. При отсутствии или неработающем зеркале - прозвонить кандидатов из реестра `data/registries/pip-mirrors.md` (при отсутствии файла - создать из шаблона `templates/pip_mirrors.md`), измеряя время отклика каждого; официальный источник проверять последним
3. Выбрать самый быстрый доступный
4. Записать выбранное зеркало:

```bash
mkdir -p ~/.config/pip && cat > ~/.config/pip/pip.conf << 'EOF'
[global]
index-url = <mirror_url>
EOF
```

5. Сообщить пользователю выбранное зеркало и причину выбора (время отклика)

## Реестр кандидатов

Список зеркал-кандидатов - реестр `data/registries/pip-mirrors.md` репозитория (домен `pip-mirrors`, маркер владения `generated-by: glob-cfg-pip`). Правила ведения:

- при первом запуске в репозитории реестр создается из шаблона `templates/pip_mirrors.md`
- при обнаружении мертвого URL - исключить из реестра, при появлении нового устойчивого зеркала - добавить (мерж идемпотентно по ключу)
- стойкие изменения состава кандидатов для всех репозиториев - правкой шаблона `templates/pip_mirrors.md` в хабе `project_standards`; реестр отдельного репозитория навык обновляет сам

## Критерии завершения

- `~/.config/pip/pip.conf` существует и указывает на отвечающее зеркало
- Пользователю сообщены выбранное зеркало и время отклика
- Установка зависимостей проходит успешно

## Примеры

- «pip не может скачать пакеты» -> проверить pip.conf, прозвонить кандидатов, записать лучшее зеркало, повторить установку
- «настрой зеркало pip на этой машине» -> выполнить шаги 1-5 без установки пакетов

## Ограничения

- Удаление файлов и папок репозитория - перенос в `.trash/<slug>_<YYYYMMDDHHMM>/` (карантин, `project_standards.md` 01.01.06), а не удаление; чистить `.trash/` только по явному запросу пользователя
